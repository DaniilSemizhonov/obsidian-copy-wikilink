# Копировать ссылку на файл

Плагин для Obsidian: правый клик по любому файлу → «Скопировать ссылку» копирует `[[ссылку]]`, которую можно вставить в другую заметку.

- Работает в проводнике, на вкладках, в результатах поиска — везде, где у файла есть контекстное меню.
- Заметки копируются без `.md` (`[[Идея]]`), остальные файлы — с расширением (`[[Договор.docx]]`).
- Если в хранилище несколько файлов с одинаковым именем, в ссылку добавляется путь — так же, как это делает сам Obsidian.
- Для картинок, PDF, аудио и видео есть пункт «Скопировать для встраивания» — `![[файл]]`.
- Можно выделить несколько файлов и скопировать ссылки на все сразу, каждую с новой строки.
- Команда «Скопировать ссылку на текущий файл» — на неё можно назначить горячую клавишу.

## Установка

Через [BRAT](https://github.com/TfTHacker/obsidian42-brat): «Add Beta plugin» → `DaniilSemizhonov/obsidian-copy-wikilink`, затем включите плагин в разделе «Сторонние плагины».

## Сборка

```bash
npm install
npm run build
```
